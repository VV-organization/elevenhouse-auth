# Vetrino

Typeface by Daniyar Shape (Daniyar Sharipov).
https://www.behance.net/gallery/143094015/VETRINO-FREE-FONT

The author explicitly permits free commercial use on the linked project page
(verified 2026-09-17) and requests attribution with a link to his Behance.
Original author note is preserved in AUTHOR-README.txt. The release is marked beta.

Use for landing display headings; the existing Manrope remains the text/UI face.
The file covers all 66 uppercase/lowercase Russian letters, verified with CoreText.
