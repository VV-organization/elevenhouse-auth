# Manrope

Self-hosted variable normal font, weight axis 200–800. Downloaded 2026-09-08
from the Google Fonts CSS API (Manrope v20):
https://fonts.googleapis.com/css2?family=Manrope:wght@200..800&display=swap

Unmodified WOFF2 subsets:
- Cyrillic: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggOxSuXd.woff2
- Latin: https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggexSg.woff2
- Latin extended (including the rouble sign): https://fonts.gstatic.com/s/manrope/v20/xn7gYHE41ni1AdIRggmxSuXd.woff2
